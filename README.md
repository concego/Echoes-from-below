# Echoes From Below

> Escape the room de terror top-down procedural — fantasia medieval, horror atmosférico.

## Sobre
Você é um soldado que acorda numa cripta subterrânea sem memória e sem seus pertences.
Explore, resolva puzzles, colete 3 chaves e escape — enquanto o Carrasco vaga pelos corredores.

**Plataforma:** Web (HTML/CSS/JS puro) | Empacotável com Tauri  
**Acessibilidade:** NVDA e TalkBack — navegação 100% por teclado e ARIA
